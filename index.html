Connect an existing store

Bring products in from a platform you already sell on. Export a CSV there, then import it here — SKUs, prices, stock and categories map in automatically.

S
Shopify
Shopify Admin → Products → Export → "All products" as CSV.
W
WooCommerce / WordPress
WooCommerce → Products → Export, leave columns on "All columns".
+
Any other system
Generic CSV/Excel with SKU, Name, Price, Stock columns — same importer used in Inventory.

Products are matched and updated by SKU — importing the same file twice updates prices/stock rather than duplicating. Column names from Shopify (Variant SKU, Variant Price...) and WooCommerce (SKU, Regular price...) are recognized automatically alongside plain SKU/Price/Stock headers.

Financial year

Close a year once its GST returns are filed — orders inside a closed year can't be edited, status-changed, or deleted by anyone, which protects what you've already filed. The next year opens automatically.

Open Settings to load financial year status.
Backups

Two backups are kept automatically — the most recent save, and a checkpoint from when this session began, so you can always undo "everything since I opened the app today." No setup needed.

Open Settings to load backup status.
